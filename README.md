🍎 Phonics Fun!

어린이를 위한 심플하고 직관적인 파닉스(Phonics) 학습 웹 애플리케이션입니다.
아이들이 그림(이모지)을 보고 소리를 들으며 단어의 첫 글자를 맞추는 과정을 통해 자연스럽게 알파벳과 소리의 연결 고리를 학습할 수 있도록 설계되었습니다.

✨ 주요 기능 (Features)

원포인트 학습 목표: "단어의 첫 알파벳 소리 연결하기"라는 단 하나의 명확한 목표에 집중합니다.

직관적인 인터랙션: 복잡한 과정 없이 소리를 듣고 알맞은 알파벳 버튼을 누르는 간단한 동작(1-2 Actions)만 요구합니다.

다중 감각 학습 (Multimodal): 시각적 요소(이모지, 색상 피드백)와 청각적 요소(Web Speech API를 이용한 단어 읽어주기)를 결합하여 학습 효과를 높였습니다.

즉각적인 피드백:

정답 시: 초록색 버튼 전환, 전체 단어 공개 및 정답 음성 출력, 2초 후 자동 다음 문제 이동.

오답 시: 빨간색 버튼 전환 및 흔들림(Shake) 애니메이션으로 시각적 교정.

Zero-Dependency: 외부 라이브러리나 복잡한 빌드 과정 없이 단 하나의 index.html 파일로 동작합니다.

🚀 실행 방법 (How to Use)

이 저장소를 클론하거나 index.html 파일을 다운로드합니다.

다운로드한 index.html 파일을 더블 클릭하여 웹 브라우저(Chrome, Safari, Edge 등)에서 엽니다.

화면의 그림이나 🔊 Listen 버튼을 눌러 소리를 듣고, 알맞은 첫 글자를 선택하며 게임을 즐깁니다!

🛠️ 기술 스택 (Tech Stack)

HTML5: 구조 및 시맨틱 마크업

CSS3: 스타일링 및 애니메이션 (Flexbox, Keyframes)

Vanilla JavaScript: 로직 구현, DOM 조작 및 Web Speech API(TTS) 제어

💡 기획 의도 (Design Philosophy)

이 프로젝트는 어린이를 위한 마이크로 러닝(Micro-learning) 가이드라인을 바탕으로 제작되었습니다.

ONE child group: 유아동 및 파닉스 기초 학습자

ONE learning problem: 단어와 첫 글자 소리의 매칭

5-10 minutes: 짧은 집중력에 맞춘 빠르고 경쾌한 플레이 타임

Small enough for a child to understand: 설명서가 필요 없는 직관적인 UI
